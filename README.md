# React-Weather-App
A responsive Weather App built using React.js and OpenWeatherMap API that displays real-time weather information with dynamic UI updates.


# 🌦️ React Weather App

A beautiful and responsive Weather Application built using React.js and OpenWeatherMap API.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays temperature, humidity, min & max temp
- 🌤️ Dynamic weather images (Hot / Cold / Rainy)
- ❌ Error handling for invalid cities
- 🎨 Clean UI using Material UI

---

## 🛠️ Technologies Used

- React.js
- Material UI
- OpenWeatherMap API
- CSS3
- JavaScript (ES6)
